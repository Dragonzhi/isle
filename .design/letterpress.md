# Letterpress 压印纸系统

2026-10-24

## 意图

Letterpress 不是把每个物件都做成同一种凸起按钮。案屿的落法是：

- **纸**：页面有极淡纸纤维，纸片是哑光纸面；不使用图片素材。
- **墨**：正文保持平面；只有大标题有极轻的墨压纸微阴影。
- **压印**：可点的物件凸起，可输入的物件压凹，状态章像盖章，阅读和导航保持平面。
- **层级**：控件最低、纸片次之、浮层最高；不会让每一块都抢注意力。

判断标准只有一句：**可点的凸起，可输入的压凹，可读的保持平面。**

## 表面状态

| 状态 | 用途 | 视觉 |
| --- | --- | --- |
| 浮层 | 对话框、筛选菜单 | 4px 硬边 + 深投影 + 纸面顶部高光 |
| 纸片 | 项目卡、上下文卡、任务组、摘要/留痕/Git、Skill、notice、error | 2px 硬边 + 浅投影 + 顶部 1px 高光 |
| 纸键 | 主/次按钮、工具按钮、图标按钮、视图切换、转移标签、字号选项 | 纸面渐变 + 2–3px 硬边 + hover 上浮 + active 回压 |
| 压凹 | 输入框、textarea、select、代码/pre、git hash、标签、任务计数、子工作区、已完成组、空态 | 内阴影 + 深色上边 + 浅色下边 |
| 盖章 | 品牌标记、状态章、项目旗标、日期/统计小字、kbd | 描边 + 轻微内凹/键帽 + 极小文字阴影 |
| 平面 | 正文、表格内容、tab、面包屑、页脚、任务行 | 只保留墨线和排版 |

## Token

最终层在 `src/App.module.css` 末尾，核心变量：

- `--lp-edge: #b7b2a5` / `--lp-edge-strong: #a7a194`：纸的切边，比现有 `--line-dark` 更深。
- `--lp-highlight: rgba(255,255,255,.78)`：纸面顶部高光。
- `--lp-well: #efede5`：压凹纸面。
- `--lp-raise-1/2/3`：纸键、纸片、浮层三级凸起。
- `--lp-press-1/2`：输入/代码/标签两级压凹。
- `--lp-grain`：内联 SVG 纸纤维，约 3.5% 透明度，只铺页面底层、页头和工具条。

硬边颜色不使用纯黑；投影使用暖墨色 `rgba(29,37,34,…)`，避免变成塑料。

## 物件映射

- **页头**：品牌岛形图标收进 32px 苔绿小方印；项目头下方有双墨线；大标题只做轻墨压。
- **工具栏**：tab 保持印刷平面；视图切换、`···`、刷新是纸键。
- **工具条**：一条压凹工具槽，里面六个操作是小纸键；移动端两列。
- **项目卡**：纸片浮起；左侧状态墨条保留；子工作区是压凹浅槽。
- **详情**：上下文卡、任务组、摘要/留痕/Git、Skill 都是纸片；任务行本身保持平面。
- **表单**：输入/textarea/select 压凹；checkbox 是纸面小方格，选中后墨色盖印；转移标签选中时压凹。
- **弹窗/菜单**：纸面浮层 + 4px 硬边；关闭键是 30px 纸键；菜单项 hover 压凹。
- **状态/标签**：状态章纸面盖章；tag/focus chip 是压凹小标签。
- **空态/提示**：空态是压凹纸坑；notice 浮起；warning 压凹；error 是陶土红纸片。
- **代码/数字**：`pre`、`code`、`gitHash` 压凹；`kbd` 是键帽。
- **阅读**：正文不加深阴影、不加纹理，保留 Noto Serif SC 的长文栏宽。

## 交互

- 纸键 hover 上浮 1px、硬边加高；active 回压 1px，去掉外投影并加内压痕。
- 压凹控件 hover 只加深切边，focus 保留 2px 墨色光圈并加内阴影。
- 所有新动效只动 `transform` / `opacity` / `box-shadow`；`prefers-reduced-motion` 下不移动。
- `forced-colors` 下移除阴影，恢复系统 checkbox，所有表面回退到 1px 系统边框。

## 边界

- 不改变信息架构、路由、字体家族、05 配色和字号设置。
- 不给正文/表格内容/导航加立体，避免阅读噪声。
- 不新增依赖、外部图片或服务端字段。
